# Plain-language results and warning points

All seven live result types share a visual warning gauge, plain-language takeaway, completed/missing check cards, up to three warning explanations (strongest first), quoted evidence, and one immediate next step. Existing previews, retry/reset actions, tabs and technical evidence remain available. Technical overview details are collapsed by default. Changes are scoped to the result section, with mobile spacing fixes there.

Warning points are a transparent frontend display guide, not a calibrated probability of fraud, authenticity, or safety. Strong observations contribute 85 points and caution observations 30. Further unique observations add 15% of their points, capped at 99. A known listed threat sets at least 95; an actual malware signature match sets 100. Case/whitespace-normalized repeated observations count once. Missing tools do not lower or inflate observed-warning points; incomplete status is independently displayed. Zero points with missing checks explicitly does not confirm safety. The API's uncalibrated numeric score remains null; display points are calculated from its actual observations.

Saved metadata-only views and illustrative demos show a dash and request a new real submission instead of inventing points. Raw content is not added to persistent history. Media scores assess observed suspicious content, never deepfake/voice authenticity.

Verification: nine meaningful Node tests cover duplicate evidence, incompleteness, metadata/demo results, known signatures/reputation, check counting, all seven real API report shapes, plain-language categories, and strongest evidence ordering. Production Vite build and diff checks pass. Browser checks used real submissions; Message 94, Offer 85, incomplete Link and QR 0, OTP Screenshot 99, Document 99, and ordinary-image Media 0 warning points. All seven were submitted through the real browser forms. Media retained its explicit unavailable-authenticity notice. Mobile result elements fit within a 390 px viewport after scoped spacing fixes. Backend AI was disabled for brief presentation testing; no model downloads or authenticity claims were introduced.
